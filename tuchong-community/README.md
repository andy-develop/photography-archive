# 图虫社区 UGC 缩略图存档 (tuchong-community)

本目录是**图虫社区（tuchong.com）公开 UGC 摄影作品的长边 1200px WebP 缩略图存档**，用于个人摄影素材整理与归档展示。

## 数据来源

- 来源站点：[图虫 tuchong.com](https://tuchong.com)
- 采集方式：按标签分别抓取 `weekly` / `daily` / `latest` 三种排序下的公开作品列表，下载其展示用缩略图。
- 覆盖标签：**28 个**（见下方目录结构）。
- 图片规格：WebP（q75），长边统一缩放至 **1200px**，平均约 90KB/张。


## manifest.csv 字段说明

UTF-8 (带 BOM)，字段顺序如下：

| 字段 | 含义 |
| --- | --- |
| `image_id` | 图虫图片唯一 ID（跨分片去重主键） |
| `title` | 作品标题 |
| `excerpt` | 作品摘要/正文节选（可能含换行） |
| `keywords` | 作品参与的话题/标签 |
| `post_url` | 原作品帖子 URL |
| `image_source` | 原图（大图）URL |
| `published_at` | 发布时间 |
| `width` / `height` | 原图宽/高（像素） |
| `local_path` | 本存档内相对路径，形如 `images/标签/文件名.webp` |

## 去重说明

- 原始抓取来自两个分片（manifest_s1 / manifest_s2），合计 46,839 条记录。
- 以 `image_id` 为主键跨分片去重，保留首次出现记录（s1 优先），共丢弃 **3,468** 条跨分片重复记录。
- 同一图片若出现在不同帖子中（文件名不同），仅保留首次记录对应的文件，其余文件不入选。
- 去重后最终保留 **43,371** 个文件，与 manifest.csv 行数一一对应。
